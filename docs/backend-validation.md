# Проверка backend

2026-09-23, Python 3.12, Windows. Ключи внешних LLM-провайдеров не настроены.

- `python -m pytest -q`: 131 проверка прошла, включая сброс переполненного WS-аудио.
  Внешние LLM/STT/TTS здесь не вызываются.
- Frontend: `pnpm test` — 3 проверки прошли; `pnpm build` — TypeScript и production build прошли.
- Локальный smoke: `/health` вернул ok, UI на 4173 и Streamlit на 8501 ответили 200;
  демо-ход через `/api/turn` выбрал SC33 и спросил город.
- Валидированы 40 сценариев, 3 системных намерения, 43 слота, 31 действие, 13 разделов KB,
  11 клиентов; ссылки, дата среза, двуязычные вопросы и отсутствие дубликатов.
- Dev: 104 реплики — 52 RU, 45 KK, 7 mixed; 84 single, 13 multi-intent, 4 out_of_scope,
  3 unclear. Все ожидаемые ID существуют.
- Проверены суммы 38000, 15400, 163800; preview без записи, запрет записи без согласия,
  изменение параметров, отказ, повтор операции, изоляция, очередь и возврат к теме.
- HTTP-контракт и WebSocket frontend проверены с подменой внешнего провайдера:
  ID событий, повтор request_id, отсутствие действий при сбое LLM.
- Проверен вход в каждый из 40 сценариев и успешный вызов каждого из 31 мок-действия.
  Для всех 9 необратимых действий проверены запрет без согласия, preview без записи и
  идемпотентный повтор. Для 10 диалогов проверены результаты: оформление, отсутствие
  незапрошенного продления, жалоба, возврат 163800, запись, документы, отсутствие дубля
  сообщения о мошенничестве. Решения маршрутизатора взяты из разметки;
  это проверка контроллера, не оценка понимания моделью.
- Проверены покупка/продление с последующим SMS, отдельное согласие на каждое изменение,
  подтверждение вместе с новым вопросом, роль полиса виновника, конфликт идентификаторов,
  срочное ДТП до сбора всех слотов, ошибки сервиса с одним повтором и закрытие сессии.
- Серверный голосовой WS-путь проверен с подменёнными STT/LLM/TTS: аудиовход → текст →
  сценарий → ответ → сегмент звука. Это проверка протокола, не качества распознавания.
- Отдельный реальный вызов Edge TTS вернул MP3 для русского и казахского приветствий
  (по 26064 байта, разные SHA-256). Файлы в игнорируемом `runtime/voice-check/`.
  Прослушивание человеком и начало воспроизведения в браузере не проверялись.

`python scripts/evaluate_router.py` остановлен из-за отсутствия ключа настроенного LLM-провайдера.
