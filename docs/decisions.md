# Решения начального backend

Это начальный текстовый срез с контроллером, мок-действиями и адаптерами провайдеров.
Полная приёмка всех страховых операций и реальной речи ещё не выполнена.

- LLM подключается через конфигурируемый OpenAI-compatible JSON API; `auto` предпочитает
  OpenAI, а Groq может быть выбран как необязательная совместимая альтернатива. Ответ
  локально валидируется Pydantic с одной попыткой исправления. Provider-side strict schema не заявляется.
- Все 40 сценариев и 3 системных намерения передаются модели с границами и контекстом.
  Оптимизация задержки ещё не проводилась. Dev-метки в промпт не передаются.
- Ключ — только в .env. Без него явный режим mock: произвольные фразы не классифицируются;
  ручной выбор сценария служит проверкой исполнителя и не входит в оценку LLM.
- Дата — 2026-10-01. Источник фактов — KB. Исходный датасет не меняется. История — до
  10 пар реплик; активные слоты, очередь и стек сохраняются отдельно.
- Пороги 0.75/0.45 — политика по оценке модели, а не калиброванная вероятность.
  Составное подтверждение извлекается LLM в поле confirmation. Оно действует только
  на существующий preview при неизменных параметрах. Новый вопрос попадает в очередь;
  срочный запрос прерывает операцию и аннулирует прежнее подтверждение.
- Подтверждение связано с копией параметров и operation_id. Изменение параметров
  аннулирует preview. request_id предотвращает повторную обработку HTTP/WS.
- После исполненного изменения ошибка доставки не разрешает повторную покупку при
  изменении параметров. Такой запрос передаётся оператору вместе с результатом операции.
- SC18 читает get_claim для уже известного номера заявления: это внутреннее расширение
  списка действий сценария по примерам D03/D08, чтобы использовать missing_documents и
  next_step, не придумывая статус и не переспрашивая известный продукт.
- Из SC01 в SC02 переносятся только параметры расчёта ОГПО. Несвязанные темы имеют отдельные слоты.
- WebSocket адаптирован к frontend из 31a893f; HTTP возвращает text, state и trace.
- STT через совместимый API работает после завершения записи, Edge TTS — по предложениям.
  Streamlit не измеряет начало воспроизведения в браузере, поэтому итоговый TTFA неизвестен.
- Изменения данных изолированы по сессиям. Отправка SMS, документов и передача оператору —
  проверяемые моки, без внешнего исполнения.
- ОГПО по умолчанию на 12 месяцев; функция расчёта принимает 6 месяцев. Отдельного
  разговорного слота срока в этой версии нет.
- КАСКО: Standard без франшизы по умолчанию. Ставки для возраста 11–15 лет не
  экстраполируются. Lite пока не выделен как дополнительный разговорный слот.
- Туристические зоны заданы для явно перечисленных стран; остальные требуют оператора.
  Округление — Python round до целого тенге.
- Возврат: полные календарные месяцы до следующего дня после end_date, максимум 12,
  коэффициент 0.9; после выплаты возврат отклоняется. Проверен D07: 163800.
- Добавление водителя без доплаты поддержано при неизменном коэффициенте ОГПО.
  Изменение тарифа и автомобиля требует оператора: формулы доплаты нет.
- Продление создаёт новый годовой расчёт поддержанного продукта со статусом awaiting_payment.
  Это допущение демо, а не подтверждённое правило компании.
- Расписание — отдельная синтетическая fixtures/schedule.json. Preview не занимает слот,
  execute резервирует его в сессии. Запись к специалисту кроме терапевта требует оператора:
  направления и полная проверка допуска отсутствуют в наборе.
- Исторический случай проверяется по дате происшествия. Полис виновника SC12 имеет
  отдельную роль и не обязан принадлежать заявителю.

Документация: OpenAI-compatible chat/audio API; [Streamlit microphone](https://docs.streamlit.io/develop/api-reference/widgets/st.audio_input).
