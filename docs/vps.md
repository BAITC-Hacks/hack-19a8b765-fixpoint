# VPS без домена

Для демонстрации: Ubuntu 24.04, 2 vCPU, 4 ГБ RAM, 40 ГБ SSD.
Это стартовая конфигурация, пропускная способность нагрузочным тестом не подтверждена.

Установить Docker Engine, Compose v2 и Python 3. Поместить проект в `/opt/saqta`,
создать `.env` с серверными настройками и ключом, затем выполнить от root:

```bash
cd /opt/saqta
bash scripts/vps-up.sh
```

Используется отдельный `docker-compose.vps.yml`: один процесс FastAPI,
собранный React под Caddy и Cloudflare Quick Tunnel. API не публикует порт на
внешнем интерфейсе; Caddy доступен локально на 127.0.0.1:8080. HTTPS и WSS
предоставляет туннель. В backend разрешается точный origin выданной ссылки.
Контейнеры перезапускаются автоматически; архив хранится в `runtime/sessions`
на VPS. Перезапуск API прерывает активные разговоры, архив сохраняется.

Публичная ссылка выводится скриптом и сохраняется в `runtime/public-url.txt`.
После перезапуска туннеля (включая перезагрузку VPS) ссылка может измениться:
снова выполните `bash scripts/vps-up.sh`, чтобы получить её и обновить origin API.
Quick Tunnel предназначен для демонстрации и не гарантирует постоянный адрес.
Для постоянного адреса потребуется отдельная настройка домена или поддомена.

```bash
docker compose -f docker-compose.vps.yml ps
docker compose -f docker-compose.vps.yml logs --tail 60 api web tunnel
curl --fail http://127.0.0.1:8080/health
```

Не коммитьте `.env`, SSH-ключи и runtime. Они исключены из Docker build context.
Приложение пока не имеет авторизации: получатели ссылки могут обращаться к API
и архивам; запросы к моделям используют серверный ключ. Использовать для
ограниченного демо. Полноценный голос проверяется отдельно реальным микрофоном.
