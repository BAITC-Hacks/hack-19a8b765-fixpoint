# FixPoint / Saqta Voice Agent

Голосовое демо вымышленной Saqta Insurance на данных `case/voice_router_dataset`.
Актуальный порядок работ — `docs/roadmap.md`, фактическое состояние — `docs/progress.md`.

## Streamlit: запуск и бесплатное размещение

Streamlit-версия работает как отдельное приложение и использует ту же серверную
логику без отдельного FastAPI-сервера. Локально из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

Откройте адрес, который покажет Streamlit (обычно `http://localhost:8501`). Для
голосового ввода браузеру потребуется разрешить доступ к микрофону. Без ключа
приложение показывает интерфейс и загруженный каталог, но не отправляет запросы
в LLM, распознаватель речи или синтезатор.

Для публикации выберите этот GitHub-репозиторий в
[Streamlit Community Cloud](https://share.streamlit.io/), укажите ветку `main`
и файл `streamlit_app.py`. В настройках приложения добавьте `OPENAI_API_KEY` в
Secrets. Ключ нужен для LLM, STT и TTS; храните его только в Secrets сервиса или
локальном `.env`, никогда не добавляйте в Git. После публикации Community Cloud
выдаст фактический адрес вида `*.streamlit.app`. Публичная ссылка появится здесь
после успешного создания приложения.

Community Cloud предназначен для демо: состояние разговора хранится в памяти
текущей Streamlit-сессии, а локальные архивы FastAPI не используются этим
самостоятельным интерфейсом. При перезапуске приложения разговоры в Streamlit
сбрасываются. Для архивирования и API используйте FastAPI, описанный ниже.

## Запуск сайта

Нужны Python 3.12+ и Node.js 22.12+ с pnpm. Из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
Copy-Item .env.example .env
```

Впишите `OPENAI_API_KEY` только в серверный `.env`. Три адаптера настраиваются
отдельно: `LLM_MODEL`, `STT_MODEL`, `TTS_MODEL`, `TTS_VOICE`. Дата Case фиксирована
как 2026-10-01. Если ключа нет, API запустится, но реальные реплики не будут
обрабатываться; для локальных тестов доступен явно обозначенный `MOCK_MODE=true`.

Терминал 1:

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Терминал 2:

```powershell
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://127.0.0.1:4173. Основной экран запускает разговор одной кнопкой:
запись заканчивается после паузы, аудио идёт в FastAPI, ответ озвучивается серверным
TTS, затем микрофон включается снова. Используйте `?dev=1` для текстового ввода
и трассировки, `?jury=1` для постоянной трассировки без текстового ввода.
Распознанная реплика и текст ответа видны на основном экране.
После каждого обработанного хода там же отображается confidence первого сценария;
подробные оценки всех сценариев доступны в трассировке.
Микрофон требует localhost или HTTPS. При удалённом запуске настройте HTTPS/WSS.

## Проверки

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe scripts/validate_dataset.py
cd frontend
pnpm test
pnpm run build
```

`python scripts/evaluate_router.py` вызывает реальный OpenAI API для dev-набора
и требует ключ. Результаты пишутся в `reports/`. Данные Case не меняются;
активные изменения клиентов и полисов изолированы по сессиям. После перезапуска
новый разговор начинает с исходных моков; результаты прежних разговоров остаются в архиве.
Реальные SMS, платежи и звонки оператору не выполняются.

## Сохранённые разговоры

Сессии автоматически сохраняются в `runtime/sessions/<session_id>.json` при создании,
при принятии запроса, после каждого хода и после измерения начала воспроизведения.
Папка исключена из Git. Для другого расположения задайте серверную настройку
`SESSION_ARCHIVE_DIR` (предпочтительно абсолютный путь).

Откройте **dev → Сохранённые разговоры → Обновить архив**, выберите разговор.
Там доступны полная история реплик и ответов, трассировки всех ходов и скачивание JSON.
Экспорт также содержит снимок состояния, результаты моков, журнал действий и ошибки.
Аудиозаписи, содержимое аудио TTS и серверные API-ключи в архив не включаются.

«Завершить» и «Сбросить» закрывают живую сессию, сохраняя её архив. После перезапуска
незавершённые разговоры помечаются как прерванные и открываются только для просмотра:
старые подтверждения и действия автоматически не возобновляются. Это локальное демо
без аккаунтов; архивы доступны через API запущенного приложения. Хранилище рассчитано
на один серверный процесс. В Docker Compose папка `runtime/sessions` примонтирована с хоста.
Старые разговоры, удалённые до включения сохранения, автоматически восстановить нельзя.

HTTP и WebSocket события описаны в [контракте](docs/backend-api.md). Реальные
RU/KK/mixed голосовые прогоны и полная приёмка сценариев ещё не выполнены.
