# FixPoint / Saqta Voice Agent

Голосовой помощник вымышленной страховой компании Saqta Insurance. Требования и архитектура: `AGENTS.md`, `docs/implementation-plan.md`. Исходные данные: `case/voice_router_dataset/`.

## Frontend

Простой чат на React + TypeScript + Vite. Диагностика свёрнута по умолчанию. Работа выполняется в `frontend/`; предыдущий статический дизайн не является приложением.

Требуются Node.js 22.12+ (либо 20.19+) и pnpm. Из корня репозитория:

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://127.0.0.1:4173. При удалённом запуске распознавание требует HTTPS. Встроенные браузеры могут не поддерживать речевой сервис; проверять в обычном Chrome с доступом к микрофону и интернету.

```sh
pnpm build
pnpm test
```

### Что работает сейчас

- Текстовый чат, Enter для отправки, Shift+Enter для переноса, сброс разговора.
- Кнопка микрофона вызывает настоящий Web Speech API, показывает промежуточный текст и помещает окончательную транскрипцию в поле ввода. После проверки пользователь отправляет её в чат.
- Язык распознавания выбирается явно: `ru-RU` или `kk-KZ`. Нет обещания автоматического распознавания смешанной речи; доступность языков зависит от браузерного сервиса.
- Обработка отказа доступа, отсутствия устройства, сетевой ошибки, отсутствия речи; остановка записи и очистка при сбросе/размонтировании. Ограничение записи — 60 секунд.
- Подготовлен клиент текстового API из плана: создание сессии, WebSocket, серверные ответы и трассировка. Vite проксирует `/api` на `http://127.0.0.1:8000`.
- Сворачиваемая диагностика, выбор реплики, экспорт JSON, неизвестные задержки не заменяются нулями.
- Ответ сервера можно озвучить через браузер, если установлен голос выбранного языка; озвучивание останавливается отдельно.

### Границы текущего этапа

Backend и LLM/STT/TTS-провайдеров в репозитории пока нет. Без backend сообщения сохраняются только в памяти вкладки, с явной меткой; ответы AI, сценарии, метрики и операции не имитируются. «Подключить сервер» начинает новую серверную сессию; локальные черновые сообщения в неё автоматически не переносятся.

Web Speech API — временная проверка ввода, а не итоговая серверная голосовая интеграция. Аудио может передаваться речевому сервису браузера. Реальная речь RU/KK/mixed ещё не проверена. Нужен отдельный выбор и тест STT/TTS-провайдеров для финального MVP.

Автоматическое восстановление WebSocket, поток бинарного аудио и сквозные голосовые измерения пока не реализованы. При разрыве последняя операция не повторяется автоматически. Согласуемые поля событий описаны в `docs/frontend-integration.md`.
